شرح كود نظام التسجيل

في هذه الصفحة نشرح كيفية عمل صفحة التسجيل والـ API باستعمال FastAPI وتخزين البيانات في CSV.

العودة إلى صفحة التسجيل

1. استيراد المكتبات (Imports)

نستورد مكتبة FastAPI لإنشاء السيرفر، وForm لاستقبال بيانات الاستمارة، وFileResponse لإرجاع هذه الصفحة، ومكتبة csv للتعامل مع ملف البيانات.

from fastapi import FastAPI, Form
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import FileResponse
import csv

2. إنشاء تطبيق FastAPI وإعداد CORS

نقوم بإنشاء التطبيق وتفعيل إعدادات السماح (CORS) لتمكين المتصفح من إرسال الطلبات للسيرفر من أي مصدر دون مشاكل أمان.

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

3. إنشاء مسار التسجيل (POST Endpoint)

نحدد المسار /register باستقبال طلبات POST لاستقبال بيانات المدخلات من استمارة HTML بنجاح.

@app.post("/register")
async def register(
    full_name: str = Form(...),
    phone: int = Form(...),
    email: str = Form(...),
    password: int = Form(...),
    city: str = Form(...)
):

4. حفظ البيانات داخل ملف CSV

نفتح الملف users.csv للإضافة، ونتحقق إن كان الملف فارغاً لنكتب العناوين (Headers) أولاً ثم نضيف صف البيانات الجديد.

headers = ["Name", "Phone", "Email", "Password", "City"]
user_data = [full_name, phone, email, password, city]

with open("users.csv", mode="a", newline="", encoding="utf-8-sig") as file:
    writer = csv.writer(file)

    if file.tell() == 0:
        writer.writerow(headers)

    writer.writerow(user_data)

5. إرجاع الصفحة وتأكيد الحفظ

بعد حفظ البيانات، نطبّع رسالة تأكيد بالـ Terminal ونعيد ملف done.html ليظهر للمستخدم مباشرة.

print("The data has been successfully saved to the users.csv file!")

return FileResponse("done.html")

6. أمر تشغيل السيرفر (Terminal Command)

لتشغيل التطبيق عبر السيرفر المحلي uvicorn وإعادة التشغيل التلقائي عند التعديل:

python -m uvicorn ahmad:app --reload
